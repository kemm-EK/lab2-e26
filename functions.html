calc()

Med denne CSS

.card {
  --spacing: 1rem;

  padding: var(--spacing);
  border-radius: calc(var(--spacing) / 2);
}

... beregnes card'ets border-radius til at være det halve af card'ets padding.

minmax()

minmax() er en grid-property. Det er almindeligt at bruge den til at definere responsive kolonner:

.gallery {
  display: grid;
  grid-template-columns: repeat(3, minmax(200px, 1fr));
  gap: 1rem;
}

clamp()

clamp() giver mulighed for at definere en mindsteværdi, en idealværdi og en maximalværdi:

h1 {
  font-size: clamp(1.5rem, 1rem + 2vw, 3rem);
}

Specielt ved clamp() er at matematiske udtryk virker uden brug af calc().
