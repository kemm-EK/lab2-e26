CSS Transforms

Eksempler på CSS transforms

Dette billede er vendt på hovedet med følgende CSS:

.turn-around {
  transform: rotate(180deg);
}

Her er 3 billeder. Det øverste er normal størrelse, det midterste er halv størrelse og det nederste er halvanden gange større end originalen.

Her er CSS'en:

img:nth-of-type(2) {
  transform: scale(0.5);
}
img:last-child {
  transform: scale(1.5);
}

Dette billede er flyttet sin egen bredde til højre (x-aksen).

Da rammen er 2 pixels bred er der lagt 2px til billedets bredde som er 100%:

img {
  width: 100%;
  transform: translateX( calc(100% + 2px) );
}

Denne tekst er både roteret og skew'et med CSS. Skew bruges i dette tilfælde til at rette feltets kanter op, så de ikke er skrå OG i <p>-elementet bruges skew til at rette teksten op så den stadig følger roteringen.

Her er CSS koden:

div {
  transform: rotate(-10deg) skew(-10deg);
}
div p {
  transform: skew(10deg);
}
