Text på billede med position

CSS koden:

.container {
  position: relative;
  .text-overlay-position {
    font-family: "Iso", serif;
    font-size: 2rem;
    -webkit-text-stroke: 1px hsl(240, 70%, 95%);
    text-shadow: 3px 3px 1px rgba(0, 0, 0, 1);
    position: absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
    text-align: center;
} }

Card Title

This is a card with text overlay on the image.

Her er CSS koden:

.container {
  .card-overlay {
   background-color: rgba(0, 0, 0, 0.5);
   padding: 5px;
   border-radius: 5px;
   font-family: "Geo", serif;
   font-size: 1rem;
   width: 40%;
   height: max-content;
   color: rgb(228, 240, 251);
   text-shadow: 3px 3px 1px rgba(0, 0, 0, 1);
   justify-self: right;
   transform: translate(-15px, 10px);
   text-align: center;
  }
  h2,
  p {
   margin: 3px;
  }
}

Her er CSS koden:

.overlay-image {
  width: 30%;
  transform: translate(200%, -11.5%);
  }
}

Alternativt kan det gøres med position:

.container {
  position: relative;
  .overlay-image {
   width: 30%;
   position: absolute;
   top: -7%;
   right: 8%;
}
