CSS pseudo classes

:is()

Denne CSS:

main h1,
main h2,
main h3 {
  color: darkgreen;
}

Kan forenkles til:

main :is(h1, h2, h3) {
  color: darkgreen;
}

Ligeledes kan

header h1, 
header h2, 
header h3, 
main h1, 
main h2, 
main h3, 
footer h1,
footer h2,
footer h3 {
  margin-bottom: 1rem;
}

Forenkles til

:is(header, main, footer) :is(h1, h2, h3) {
  margin-bottom: 1rem;
}

:has()

Med denne HTML

<article>
  <h2>Artikel med billede</h2>
  <img src="photo.webp" alt="Landscape">
</article>

<article>
  <h2>Artikel uden billede</h2>
  <p>Kun tekst i denne artikel.</p>
</article>

Kan den første <article> vælges med denne CSS:

article:has(img) {
  background-color: lightblue;
}

:not()

Med denne HTML:

<button>Gem</button>
<button class="secondary">Annuller</button>
<button>Slet</button>

Kan den første og sidste <button> vælges samtidigt med at den midterste fravælges (pga. sin class) med følgende CSS:

button:not(.secondary) {
  background-color: darkblue;
  color: white;
}
