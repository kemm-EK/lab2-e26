Her er tre employee cards præsenteret. ::before bruges til at indsætte telefon & email-ikoner.

Koden:

.tel::before {
  content: "📞 ";
  margin-right: 0.5rem;
}
.email::before {
  content: "✉️ ";
  margin-right: 0.5rem;
}

Hover-effekten på billedet er lavet med transition og filter.

Her kan koden ses:

img {
  transition: filter 0.6s;
  &:hover {
   filter: brightness(120%);
  }
}

Både ::before og ::after bruges sammen med position efter <h2> til at lave den mørkere kant i top og bund af kortet.

Koden

h2::before {
  content: "";
  position: absolute;
  left: 0;
  top: 0;
  width: 100%;
  height: 20px;
  background-color: var(--card-edge-color);
}
h2::after {
  content: "";
  position: absolute;
  left: 0;
  bottom: 0;
  width: 100%;
  height: 20px;
  background-color: var(--card-edge-color);
}

Eksempel 2: Overlay og tegn

A building in Berlin

A canal in Copenhagen

Two boats on Møn

I dette eksempel bruges ::before til at lave et overlay over billedet, der er gråt og gennemsigtigt. Det er dog også usynligt indtil man kører musen henover et billede.

Eksemplet bruger også ::after til at lave et circle plus oven på billedet. Tegnet sættes ind i et <a> element, så det er klikbart og kan åbne en ny fane med billedet i. Dette gøres med target="_black" i anchor-tagget.

Vi vælger at bruge en grid-løsning til linket selvom man kunne bruge position. Det gør vi for at højne tilgængeligheden.

Her er CSS koden:

.gallery-item::before {
  content: "";
  position: absolute;
  inset: 0;
  background: rgb(0 0 0 / 40%);
  opacity: 0;
  transition: opacity 250ms;
  pointer-events: none;
}

.gallery-item {
  display: grid;
  aspect-ratio: 5 / 3;
  overflow: hidden;
 
  > * {
   grid-area: 1 / 1;
  }
 
  img {
   width: 100%;
   height: 100%;
   min-height: 0;
   object-fit: cover;
  }
  .zoom {
   place-self: center;
   z-index: 1;
   text-decoration: none;
   cursor: zoom-in;
 
   &::after {
    content: "⊕";
    display: block;
    font-size: 3rem;
    color: white;
    opacity: 0;
    transition: opacity 250ms;
   }
  }
 
  &:hover .zoom::after,
  .zoom:focus-visible::after {
   opacity: 1;
  }
}
